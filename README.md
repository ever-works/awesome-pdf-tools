- [DocRaptor](https://docraptor.com/) - DocRaptor is a commercial HTML-to-PDF API service that converts HTML and CSS to PDF documents. - [Gotenberg](https://gotenberg.dev/) - Gotenberg is an open-source API for converting HTML, Markdown, and Office documents to PDF using Docker. ([Read more](/details/gotenberg.md)) `Open Source` `Self-Hosted` `API` `Docker` `HTML to PDF`
- [PDFShift](https://pdfshift.io/) - PDFShift is a cloud-based HTML-to-PDF conversion API for developers. ([Read more](/details/pdfshift.md)) `Paid` `API` `HTML to PDF` `Cloud` `REST`
- [Puppeteer](https://pptr.dev/) - Puppeteer is an open-source Node.js library that controls headless Chrome or Chromium. ([Read more](/details/puppeteer.md)) `Open Source` `Node.js` `Headless Chrome` `API` `Automation`
- [wkhtmltopdf](https://wkhtmltopdf.org/) - wkhtmltopdf is an open-source command-line tool for converting HTML to PDF using the WebKit rendering engine.
